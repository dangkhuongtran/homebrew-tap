# Dangkhuongtran Tap

## How do I install these formulae?

`brew install dangkhuongtran/tap/<formula>`

Or `brew tap dangkhuongtran/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dangkhuongtran/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
